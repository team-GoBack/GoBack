# GoBack.

> **당신의 사연을 고백(告白)해주세요. 후회를 되돌려 드립니다.**

익명으로 고민을 털어놓고, 다른 사람들의 투표와 경험담으로 선택을 돕는 커뮤니티입니다.
사연자는 투표가 끝난 뒤 최종 선택을 공개하고, 후일담으로 "그래서 어떻게 됐는지"까지 들려줍니다.

## 기획 의도

지나간 선택은 되돌릴 수 없습니다. 하지만 지금 앞에 놓인 선택은 아직 바꿀 수 있습니다.
"그때 이렇게 했더라면" 하는 후회를 줄이기 위해, 고민을 익명으로 털어놓고 여러 사람의 경험을 빌려 오는 공간을 만들었습니다.

GoBack은 투표로 끝나지 않고 사연자의 최종 선택과 후일담까지 이어지도록 만들어, 조언한 사람도 결과를 확인할 수 있게 했습니다.

- **익명**: 이메일·이름 없이 "익명1, 익명2"로만 표시
- **블라인드 투표**: 투표하기 전에는 결과와 댓글이 보이지 않아, 남의 의견에 휩쓸리지 않고 고름
- **끝까지 이어지는 이야기**: 마감 → 최종 선택 공개 → Best Pick → 후일담 → 참여자에게 알림

## 주요 기능

### 사연
- 사연 작성: 제목, 내용, 카테고리(연애 · 학업·진로 · 인간관계 · 재테크 · 일상 · 기타, 필수 선택), 선택지 2\~5개, 투표 시간(1시간 · 1일 · 1주일 · 직접 15분\~30일)
- 후일담 약속: 작성할 때 "나중에 후일담을 남길게요"를 표시
- 수정 · 삭제 · 지금 마감하기 

### 투표
- 선택지를 고르고 이유(경험담) 댓글과 함께 투표, 1인 1투표
- 블라인드: 투표 전에는 결과·댓글 숨김. "궁금해요"를 누르면 투표를 포기하고 결과를 먼저 볼 수 있음
- 남은 시간 타이머, 마감되면 결과 화면으로 자동 전환

- 추천 버튼

### AI 답변
- 사연자는 언제든 "AI에게 물어보기"로 AI(Gemini)의 의견을 받을 수 있음 (사연당 1번, 저장됨)

### 마무리와 후일담
- 사연자 마무리: 마감 후 최종 선택 공개 + 가장 도움이 된 댓글을 Best Pick으로 선정 
- 후일담: 마감 후 사연자가 원할 때 여러 번 작성, 타임라인으로 표시

### 알림
지나간 알림은 내 활동의 🔔 종에서 모아 볼 수 있고, 안 본 알림 수가 빨간 숫자로 표시됩니다.
- ⏰ 사연자: 마감된 내 사연이 최종 선택을 기다려요
- 🏆 투표자: 내 댓글이 Best Pick으로 뽑혔어요
- 🗳️ 투표자: 내가 투표한 사연의 최종 선택이 공개됐어요
- 📮 투표자: 내가 투표한 사연에 새 후일담이 올라왔어요

### 둘러보기
- 메인: 제목·내용 검색, 카테고리(눌러서 펼치기) · 정렬(최신순, 투표 많은 순) · 마감된 사연 포함 토글(기본은 진행 중만), 벤토 그리드
- 카드 배지: 마감 임박 · 🔥 HOT(투표 3명 이상, 가장 HOT한 사연은 큰 칸) · 📮 후일담 약속
- 카드 정보: 작성일시, 투표 수, 남은 시간, 추천 수, 내가 투표한 사연엔 ✓ 표시
- Swipe(릴스): 아직 투표하지 않은 사연을 무작위로 한 장씩 넘기며 바로 투표
- 내 활동: 내가 쓴 사연 · 내가 투표한 사연, 검색, 목록에서 숨기기, 🔔 알림 기록, 로그아웃
- 헤더: 로그인 전에는 Swipe · 로그인 · 사연 쓰기, 로그인 후에는 Swipe · 내 활동 · 사연 쓰기

## 기술 스택

| 분류 | 사용 |
|---|---|
| 프론트엔드 | React, Vite, React Router |
| 백엔드 · DB | Supabase (PostgreSQL, Google 로그인, Row Level Security) |
| 배포 | Vercel (main 머지 시 자동 배포, 서버 함수로 AI 호출) |
| AI | Google Gemini API |
| 협업 | GitHub Organization, 브랜치 → PR → 리뷰 → 머지 |

## 구조

```
src/
├─ api/          # 화면은 이 함수들만 부름 (DB 접근은 여기서만)
│  ├─ posts.js       사연 · 선택지 · 마무리 · 내 활동
│  ├─ responses.js   투표 · 블라인드 · 결과
│  ├─ epilogues.js   후일담 · 후일담 알림
│  ├─ notices.js     마무리 필요 · 최종 선택 알림 · 알림 기록
│  ├─ recommends.js  추천
│  ├─ ai.js          AI 답변 (요청은 서버 함수로)
│  └─ auth.js        구글 로그인
├─ pages/        # 메인, 상세, 작성, 릴스, 내 활동
├─ components/   # 카드, 투표 폼, 결과, 후일담, 알림 배너·종, AI 답변 카드 등
└─ utils/        # 날짜 표시, 선택지 색 등 공통 도우미
api/
└─ ai-answer.js  # Vercel 서버 함수: 작성자 확인 → Gemini 호출 → 저장 (API 키는 여기에만)
```

## 실행 방법

```bash
npm install
# .env.local 파일에 VITE_SUPABASE_URL, VITE_SUPABASE_KEY 작성
# (AI 답변은 배포 환경에서만 동작: Vercel 환경변수 GEMINI_API_KEY, SUPABASE_SERVICE_ROLE_KEY 필요)
npm run dev
```
